# XXD Panel 081 · 日本語読解ガイド

各写真を独立した3:4ポスターにし、上部は現実写真、下部は記憶から選び取った線描と限定色の記念ポスターにします。均一なモノライン、開いた輪郭、断線、控えめな揺れ、線の減算、密度の階層、暖白の大きな余白で旅行図録・建築図解の気配を作ります。

写真から鮮やかな2〜4色を抽出し、黒線＋塗りではなく色線そのものを情報にします。線密度、明度、色コードで前後を示し、粒子・見当ずれ・不均一なインクでリソグラフ／シルク印刷の質感を加えます。ひとつの核を非対称に組み、余白に空気・距離・間・感情を担わせます。手書き風の細い文字は余白や主体の方向に沿わせ、写実、背景の塗り込み、ステッカー的な漫画、雑然としたコラージュ、商業テンプレートを避けます。
