# XXD Panel 081 · 한국어 읽기 가이드

각 사진을 독립된 3:4 포스터로 만들고 위쪽은 현실 사진, 아래쪽은 기억에서 골라낸 선과 제한색의 기념 포스터로 전환합니다. 균일한 모노라인, 열린 윤곽, 끊긴 가장자리, 절제된 흔들림, 선의 덜어냄, 밀도 위계와 넓은 따뜻한 흰 여백으로 여행 도록·건축 도해의 분위기를 만듭니다.

원본에서 선명한 2~4색을 추출해 검은 외곽선과 색 채움 대신 색 선 자체로 정보를 전달합니다. 선 밀도, 명도와 색상 코딩으로 깊이를 만들고 입자, 인쇄 어긋남, 고르지 않은 잉크로 리소그래프·실크 인쇄 질감을 더합니다. 하나의 시각 핵을 비대칭으로 배치하고 여백이 공기·거리·멈춤·감정을 맡게 합니다. 가는 손글씨풍 글자는 여백이나 피사체 방향을 따르며 사실적 드로잉, 가득 찬 배경, 스티커 만화, 혼란스러운 콜라주와 상업 템플릿은 피합니다.
